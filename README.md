# 👥 Customer Segmentation Dashboard

## 🎯 Project Overview
An interactive customer segmentation dashboard that uses **K-Means clustering** to analyze customer behavior, purchasing patterns, and demographics. Built with Python, Streamlit, and scikit-learn, this tool helps businesses understand their customer base and develop targeted marketing strategies.

## ✨ Key Features
- **Advanced Clustering**: K-Means algorithm with customizable parameters (2-8 segments)
- **Interactive Visualizations**: PCA projections, segment distributions, feature comparisons
- **Business Insights**: Automatic segment profiling and marketing recommendations
- **Data Flexibility**: Upload CSV/Excel files or use built-in sample data
- **Export Results**: Download segmented data for further analysis
- **Real-time Analysis**: Instant feedback when adjusting parameters

## 🔧 Technologies Used
- Python 3.8+
- Streamlit - Interactive Dashboard Framework
- scikit-learn - Machine Learning (K-Means, PCA)
- Pandas & NumPy - Data Processing
- Plotly - Interactive Visualizations

## 📊 What You Can Do
1. **Upload** your customer dataset (CSV or Excel)
2. **Select** features for clustering (age, income, purchase patterns, etc.)
3. **Choose** number of customer segments (2-8)
4. **Analyze** segments through interactive charts and visualizations
5. **Get** automatic business insights and recommendations
6. **Download** segmented customer data for marketing campaigns
